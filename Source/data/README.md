# RnR Data directory

This data directory is meant to hold the outputs of the development version of replace and route and contains the following folders:

- `output/` Where the RnR files are
  - This is created automatically
- `parquet/` Where the hydrofabric parquet files are stored. These can be downloaded at `s3://hydrofabric-data/icefabric`
- `warehouse/` Where the icefabric bakend is stored
